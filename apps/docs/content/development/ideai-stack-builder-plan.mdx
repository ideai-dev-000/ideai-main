# IdeaI AI Technology Stack Builder - Phased Plan

**Vision**: A disruptive dev suite UI that guides developers through building complete IdeaI apps step-by-step.

**Status**: Planning Phase  
**Last Updated**: January 3, 2026

---

## Overview

The IdeaI AI Technology Stack Builder is a staged, visual UI that takes developers through sequential steps to build a complete IdeaI software tool, SaaS, app, or website. It's built on the `@repo/ideai-developer` package foundation.

### Core Concept

**Staged Wizard UI** → **Complete Build-Ready App**

1. **Select Framework** → Next.js, React, etc.
2. **Select Apps** → Which apps/components to include
3. **Select CSS Framework** → Tailwind, Bootstrap, UnoCSS, etc.
4. **Configure Deployment** → Vercel, subdomain, domain
5. **Build & Deploy** → Generate complete app structure

## Phase 1: Staged UI Architecture

**Goal**: Design and implement the staged wizard UI foundation

### Architecture

```
packages/ideai-developer/
├── src/
│   ├── local/
│   │   ├── components/
│   │   │   ├── stack-builder/
│   │   │   │   ├── StackBuilderWizard.tsx      # Main wizard component
│   │   │   │   ├── StageFramework.tsx          # Stage 1: Framework selection
│   │   │   │   ├── StageApps.tsx                # Stage 2: App selection
│   │   │   │   ├── StageCSS.tsx                 # Stage 3: CSS framework
│   │   │   │   ├── StageDeployment.tsx          # Stage 4: Deployment config
│   │   │   │   ├── StageBuild.tsx               # Stage 5: Build & deploy
│   │   │   │   ├── StageProgress.tsx            # Progress indicator
│   │   │   │   └── StackBuilderState.ts         # State management
│   │   │   └── ideai-dev-tools.tsx              # Main dev tools panel
│   │   ├── cli/
│   │   │   └── stack-builder.mjs                # CLI for stack builder
│   │   └── utils/
│   │       ├── stack-config.mjs                 # Stack configuration utilities
│   │       └── app-generator.mjs                # App generation logic
```
