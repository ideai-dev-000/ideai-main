## Project Settings

### Root Directory

**Important**: The Vercel project must be configured with the correct root directory.

1. Navigate to [Project Settings](https://vercel.com/idea-i/web/settings/general)
2. Find **Root Directory** setting
3. Set to: `apps/web`
4. Save changes

This tells Vercel where to find the `package.json` and build the application.

### Build Configuration

Each app has its own `vercel.json` configuration:

- **`apps/web/vercel.json`** - Web app configuration
- **`apps/docs/vercel.json`** - Docs app configuration

Configuration includes:
- Build command (runs from monorepo root)
- Development command
- Install command
- Framework detection (Next.js)
- Output directory

## Vercel CLI

### Installation

```bash
npm install -g vercel
```

### Authentication

```bash
vercel login
```

### Linking Projects

Projects are linked via `.vercel/` directory:

```bash
cd apps/web
vercel link
```

This creates `.vercel/project.json` with project configuration.

### Manual Deployment

```bash
# Preview deployment
cd apps/web
vercel deploy

# Production deployment
vercel deploy --prod
```

### Environment Variables

Pull environment variables locally:

```bash
cd apps/web
vercel env pull .env.local
```

## Monorepo Configuration

### Build Commands

Vercel is configured to run builds from the monorepo root:

```json
{
  "buildCommand": "cd ../.. && pnpm build --filter=web",
  "installCommand": "cd ../.. && pnpm install"
}
```

This ensures:
- Shared packages are built correctly
- Dependencies are installed from root
- Turborepo orchestration works properly

### Framework Detection

Vercel automatically detects Next.js framework when:
- `package.json` contains `next` dependency
- Root directory is correctly configured
- `vercel.json` specifies `"framework": "nextjs"`

## Troubleshooting

### "No Next.js version detected"

**Solution**: Set Root Directory to `apps/web` in Vercel project settings.

### Build Fails: "Cannot find module"

**Solution**: Ensure `installCommand` runs from monorepo root.

### Deployment Fails: "Root Directory" error

**Solution**: Verify Root Directory setting matches app location.

## Best Practices

- ✅ Keep `vercel.json` in each app directory
